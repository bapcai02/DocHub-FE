# DocHub-FE

DocHub-FE is a web application that provides tools for image manipulation, including creating CSS clip-path shapes and converting images to different formats.

## Features

- **Clip Path Editor**: Create and edit various CSS clip-path shapes using an intuitive interface. Users can manipulate points, select shapes, and preview their designs in real-time.

- **Image Converter**: Convert images to different formats with ease. The tool allows users to upload images, select the desired output format, and trigger the conversion process.

## Installation

To get started with DocHub-FE, clone the repository and install the dependencies:

```bash
git clone <repository-url>
cd DocHub-FE
npm install
```

## Usage

After installing the dependencies, you can start the development server:

```bash
npm start
```

Open your browser and navigate to `http://localhost:3000` to access the application.
